# План: «Журнал» (PWA)

## Стек
Vite + TypeScript + **Preact** (+ `@preact/signals`) + **Dexie** (IndexedDB) + `vite-plugin-pwa` (Workbox) + **Vitest**.
Деплой: GitHub Pages через GitHub Actions, `base` береться з назви репозиторію.
Чому Preact: бандл ~10 КБ, логіка в чистому TS окремо від UI, тож її легко тестувати.

## Схема БД (закладається вже на етапі 1)
- Таблиці: `entries`, `categories`, `people`, `vehicles`, `items`, `locations`,
  `history` (старі версії записів після конфліктів синхро), `peers` (стан синхро з кожним пристроєм),
  `settings`, `drafts`.
- У кожної сутності, що синхронізується: `id` (uuid), `updatedAt`, `deviceId`, `deletedAt` (tombstone)
  + локальний лічильник змін `localSeq` (у файли не потрапляє).
- Інкрементальний пакет синхро = усе з `localSeq` > позначки «відправлено цьому пристрою».
- Конфлікт = запис змінено на обох сторонах після останнього обміну → старіша версія йде в `history`.
- Tombstone фізично видаляється лише після очищення кошика **і** відправлення на всі відомі пристрої.

## Навігація
- iPhone: нижній таб-бар з 5 вкладок (Запис · Журнал · Висить · Сьогодні · Вибірка), ⚙ Налаштування в шапці.
- Широкий екран: бічна панель з усіма 6 екранами, журнал і деталі у два стовпці.
- Гарячі клавіші `N`, `/`, `1–6` діють лише поза полями введення; `Ctrl/Cmd+Enter` діє завжди.

## Мої рішення (виправте, якщо не так)
1. Поля з довідників (людина/авто/майно) зберігають **текстове значення**, а довідник служить лише для автодоповнення.
   Перейменування в довіднику не ламає старі записи, підсумки групуються за текстом.
2. Категорію з записами можна лише архівувати. Порожню можна видалити (через tombstone).
3. Якщо одночасно настав чекпоінт і перше відкриття за день: спершу чекпоінт, потім «Сьогодні».
4. «Новіший» при синхро визначається за годинниками пристроїв. Про розбіжність годинників буде попередження в README.
5. Пароль до файлів синхро вводиться щоразу й ніде не зберігається.
6. `git init` і коміт після кожного етапу роблю локально. Репозиторій на GitHub створюєте й пушите ви (або я, коли скажете).
